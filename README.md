# Django LMS Project

Проект системы управления обучением (LMS) на Django с DRF.

## Функциональность

- Модель пользователя с авторизацией по email
- Курсы и уроки с CRUD операциями
- REST API для работы с данными

## Модели

### Пользователь (User)
- Email (уникальный идентификатор)
- Телефон
- Город
- Аватар

### Курс (Course)
- Название
- Превью (картинка)
- Описание

### Урок (Lesson)
- Название
- Описание
- Превью (картинка)
- Ссылка на видео
- Связь с курсом

## API Endpoints

### Курсы
- `GET /api/courses/` - список курсов
- `POST /api/courses/` - создание курса
- `GET /api/courses/{id}/` - получение курса
- `PUT /api/courses/{id}/` - обновление курса
- `DELETE /api/courses/{id}/` - удаление курса

### Уроки
- `GET /api/lessons/` - список уроков
- `POST /api/lessons/` - создание урока
- `GET /api/lessons/{id}/` - получение урока
- `PUT /api/lessons/{id}/` - обновление урока
- `DELETE /api/lessons/{id}/` - удаление урока
